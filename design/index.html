如何使用

上传 Linux 二进制后，自动分析架构和基础环境；连接 Docker 时会在受限容器里读取 --help，提取明确的默认端口和数据目录。识别不到的配置留空，可按程序文档补充。

支持单个 ELF 程序，不包含额外配置文件、自定义动态库或 Web 资源。基础环境首次使用需联网下载。导入只将镜像加入飞牛的 Docker 镜像库，不会启动应用；同名标签会指向本次导入的镜像。
